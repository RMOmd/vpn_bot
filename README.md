# VPN Telegram Bot

Telegram бот для предоставления VPN услуг с пробным периодом и платными подписками.

## Функциональность

- Пробный период на 7 дней
- Платные подписки на 1, 3, 6 и 12 месяцев
- Оплата через Telegram Wallet и Stars
- Защита от злоупотребления пробным периодом
- Админ-панель для управления сервисом
- Статистика пользователей и финансов

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/vpn-bot.git
cd vpn-bot
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/Mac
.venv\Scripts\activate     # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл .env и заполните его:
```
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite:///vpn_bot.db
```

5. Запустите бота:
```bash
python main.py
```

## Использование

1. Запустите бота командой /start
2. Выберите "Получить пробный период" или "Купить подписку"
3. Следуйте инструкциям бота

## Админ-панель

Для доступа к админ-панели используйте команду /admin. В админ-панели доступны:
- Статистика пользователей
- Список последних пользователей
- Финансовая статистика
